# 案例：用 `book-user` 的《穷查理宝典》路径分析一只 A 股个股

> 案例日期：2026-09-20
> 提问原文：`/book-user 帮我用穷查理宝典分析中际旭创`
> 配套知识包：`穷查理宝典`（1 本，单一）
> 姊妹案例：`book-user-个股分析案例-中际旭创.md`（同一标的，走 `Serenity的瓶颈点投资方法论` + `聪明的投资者`）
> 说明：本文是**方法论演示**，所有行情/财务数据来自公开披露，不构成任何投资建议。

## 1. 案例速览

| 项 | 内容 |
|---|---|
| 一句话提问 | `/book-user 帮我用穷查理宝典分析中际旭创` |
| 触发技能 | `book-user`（基于已发布知识包回答问题） |

## 2. 提问方式

### 2.1 原文

```
/book-user 帮我用穷查理宝典分析中际旭创
```

一共 20 个字符，包含四件事：

| 成分 | 作用 |
|---|---|
| `/book-user` | 技能加载开关，不能省 |
| `帮我用穷查理宝典` | **限定知识包**——这是本案例与姊妹案例的分水岭 |
| `分析` | 意图类型（要判断，不要科普） |
| `中际旭创` | 分析对象 |

### 2.2 与姊妹案例的提问差别（值得单独理解）

| | 姊妹案例 | 本案例 |
|---|---|---|
| 原文 | `/book-user 分析下A股：中际旭创` | `/book-user 帮我用穷查理宝典分析中际旭创` |
| 选书权 | 交给技能（自动选 2 本） | 收回给自己（指定 1 本） |
| 输出可预期性 | 低（取决于技能选什么书） | 高（框架固定，可复现） |
| 覆盖维度 | 产业定位 + 估值纪律 | 决策方法 + 会计纪律 + 认知偏差 |
| 代价 | 可能选到与问题匹配度一般的书 | **放弃了产业定位能力**（见 §5） |

`book-user` 的技能规范里写的是「**Choose books and chapters yourself**; the runtime does not rank or select anything」——选书本来是技能的工作。**显式指定书是合法的用法，但它把技能的选择空间压缩成了 1。**

## 3. 执行轨迹（AI 侧实际做了什么）

| 步 | 动作 | 要点 |
|---|---|---|
| 1 | 加载技能正文 | `SKILL.md` 规定：从 `booksys books list` 开始，只用目录声明的稳定 ID |
| 2 | 列目录 | 拿到 3 个知识包及其 `book_id` / `chapter_id` |
| 3 | 阅读书档案 | 读 `穷查理宝典/book.md`（章节索引 + 关键词→章节映射 + **常见误用纠正**） |
| 4 | 选章并精读 | 3 份 `concepts.json` + 1 份 `guide.md` + 6 章 `source.md`（其中 3 章按需只读关键节） |
| 5 | 定框架 | 见 §3.1 |
| 6 | 外部取数 | 通达信：行情快照（PE/PB/市值/股本）、利润表 25 期、现金流量表 24 期、主营构成、日/周 K 线 |
| 7 | 接口失败的替代 | 3 次接口不可用，改走 deep_info 与公开检索（见 §3.3） |
| 8 | 分证据等级输出 | 书中材料 / 外部事实 / 推断 三类分开标注；给置信度、证伪条件、数据缺口 |

### 3.1 选章逻辑（六章各承担什么）

| 章节 | 角色 | 为什么必须 |
|---|---|---|
| Ch4 第二章 芒格的生活、学习和决策方法 | 方法论母体 | 能力圈三分类、投资评估流程、护城河、双轨分析、十大检查清单 |
| Ch5 第三章 芒格主义：查理的即席谈话 | 投资原则 + 反面教材 | 集中投资、优秀企业定义、机会成本、**EBITDA 批评**、期权成本与稀释 |
| Ch7 第二讲 论基本的、普世的智慧 | 商业模型 | 规模优势与经验曲线、**冲浪模型**、竞争性毁灭、彩池投注 |

## 4. 结果输出

### 4.0 开场：公开加载了哪些书

只加载 1 本，并说明各章角色，同时**声明未加载的《Serenity的瓶颈点投资方法论》第 07 章就是"光通信赛道 CPO 全链条"**，留给用户决定是否追加。

### 4.1 框架给的第一句话，是"这不在我的圈里"

芒格评估的第一关是能力圈三分类，而他对这类公司的处置是书里明写的，不需要替他推断：

- Ch7：*"**伯克希尔一般并不投资这些在复杂的科技行业'冲浪'的人**……我们认为我们很难理解软件、电脑芯片等科技行业的发展的实质。"*
- Ch5：*"新股要么发行规模太小，**要么太过高科技——我们不懂它们是干什么的**。"*
- Ch7：*"IBM 成功'冲浪'60 年之后被颠下了浪尖……这是一堂生动的课，让人明白经营科技企业的难处。"*

**必须同时声明**：这是**能力圈约束，不是对公司的价值判断**。同讲里芒格留了口子——*"这并不意味着你们去做的话是不理智的行为"*。所以后续做的是"坚持用这套框架会看到什么"，而不是"芒格会不会买"。

### 4.2 三条最硬的发现

**① 最需核实的事实：利润与现金的裂口**

| | 2023 | 2024 | 2025 | 2026H1 |
|---|---|---|---|---|
| 归母净利（亿元） | 21.74 | 51.71 | 107.97 | **136.51** |
| 经营现金流净额（亿元） | 18.97 | 31.65 | 108.96 | **18.00** |
| 现金流/净利 | 85.9% | 58.9% | 94.1% | **12.2%** |

拖累项：存货 −72.39 亿、经营性应收 −92.42 亿（合计占用约 139 亿）；资本开支 48.02 亿（2025 全年仅 27.60 亿）。
两种解释并列（**战略备货** / **收入质量**），芒格的纪律不是二选一，而是把它变成待验证项 —— **判据：2026 三季报/年报现金流比是否回到 ≥80%**。

**② 估值：不是"错标赔率的马"**

芒格要的是"胜率 1/2、赔率 1 赔 3"。1.0913 万亿市值对应 2026 年约 300 亿一致预期 ≈ 33–40×，即**价格已经等于"2026 年利润再翻一倍"**。

**③ 风险是集中的，且集中在公司控制不了的地方**

境外收入 **94.8%**；前五大客户 **81.9%**、单一最大客户 **25.1%**（截至 2026-03-31，招股书口径）；高端 EML 光芯片依赖海外，瓶颈预计延续到 2027 年中；CPO/NPO 存在路线替代风险。护城河（认证 12–18 个月、代际首发领先半年）在当前代际内真实，但芒格有原话：*"旧的护城河正在被填平，而新的护城河比以前更难预测。"*

### 4.3 资本配置信号（这一节是《穷查理宝典》路径独有的产出）

| 事项 | 事实 | 芒格框架下的读数 |
|---|---|---|
| H 股上市 | 2026-07-30，净募资约 528.91 亿港元，首日一度跌 8% | 摊薄；同时带来巨额现金 |
| 回购 | 40–80 亿元，**全部用于股权激励/员工持股，而非注销** | 更接近"把股东的钱转成管理层的报酬" |
| 控股股东减持 | 2025-05 ~ 2026-07 减持 621 万股，超 53 亿元 | 内部人减持与公司回购同向发生 |
| 股息率 | 0.23% | 股东现金回报极低，利润几乎全部留在体内扩产 |

对应芒格的原话：*"他们会如何分配现金？他们是站在股东的角度上聪明地分配它吗？还是付给他们自己太多的酬劳？"*

### 4.4 必须同时放上天平的另一端

芒格承认过自己的主要失败来源是**坐失良机**：*"伯克希尔历史上最严重的错误是坐失良机的错误……这些机会成本并没有反映在财务报表上，但却让我们失去了几十亿美元。"*

**用一套"为避开重大错误而设计"的框架去评价一个 14 个月涨 404% 的标的，它在结构上必然偏向否定。** 这一条与上面所有风险提示等权，不能只留一头。

### 4.5 两张可视化

| 图 | 说明 |
|---|---|
| 归母净利 vs 经营现金流（柱状） | 把 12.2% 这个数字放进 4 期序列里，一眼看出它是近年最低 |
| 能力圈三分类落点图 | 把"太难理解"的落点连同三条书内原话依据画出来，避免读者误以为是 AI 的独断 |

### 4.6 关键不确定性 / 证伪条件

**未查到的**（明确列出，未用估算值填充）：2026H1 前五大客户占比（仅有 Q1 口径）、800G/1.6T 收入拆分（公司只披露"光通信模块"合计）、公司对现金流下降的正式解释、有息负债与汇率敞口明细、券商一致预期的一手来源。
**"二季度业绩不及预期""压制股价"** 属媒体口径的**未证实传闻**，仅有公司召开电话会议澄清的报道。

**证伪条件（4 条）**：
1. 2026 三季报/年报经营现金流/净利润回到 ≥80%、存货周转天数回落 → 推翻"收入质量"解释；
2. 客户结构显著分散（前五大降至 60% 以下）且收入未下滑 → 削弱集中度风险；
3. CPO 商用明显慢于预期、可插拔模块生命周期拉长 → 削弱路线替代风险；
4. 研发费用率回到并稳定在 5% 以上、下一代（3.2T）继续首发 → 强化"护城河每年变宽"判定。

## 5. 同标的、不同书：两个案例的对照（本案例最值得看的一节）

同一只股票、同一天、同样短的两句提问，**两本书指向的风险点几乎不重叠**：

| 维度 | 姊妹案例（Serenity + Graham） | 本案例（穷查理宝典） |
|---|---|---|
| 选书方式 | 技能自动选 2 本 | 用户显式指定 1 本 |
| 产业定位 | **五因子乘积归零**：是"受益者"不是"瓶颈点"，真正的卡点在更下面几层 | **未评估**——该书不含产业链拆解工具 |
| 估值方法 | Graham 防御型七标准 → 安全边际为负（PE×PB = 1383） | 能力圈 → 赔率（三口径 PE + "不是错标的马"） |
| 风险归因 | 受限供给 = 0（供给可扩，它自己还被上游卡） | 利润与现金裂口（12.2%）+ 客户集中 81.9% |
| 对资本配置的处理 | 未涉及 | 回购用于激励 / 内部人减持 / H 股摊薄 / 股息率 0.23% |
| 对认知偏差的处理 | 未涉及（仅用"市场先生"解释 7 月回撤） | 25 种倾向 + lollapalooza 同向叠加 |
| 对"错失"的对称处理 | 明确写"结论=不构成机会 ≠ 会跌" | 明确写"坐失良机是芒格承认的主要失败来源"，与风险提示等权 |
| 结论趋同处 | **都不构成"可以下手"的机会** | 同 |
| 结论差异处 | 因为"没有瓶颈 + 没有安全边际" | 因为"不在能力圈 + 不是错标赔率" |

### 5.1 从对照里读出的三条

1. **两本书的"不行"是不同性质的"不行"。** Serenity 说"这个环节不是卡点"，Graham 说"价格没给保护"——都是**关于标的**的判断。芒格说"我不懂"——是**关于分析者**的判断。**后者不能反驳前者，前者也不能反驳后者。**
2. **指定单本 = 放弃这本书没有的能力。** 本案例最大的空白是"产业定位"，而该标的正处在 Serenity 第 07 章明确覆盖的链上。技能规范本身就允许/鼓励加载多本互补的书；本次因为用户显式指定而未加载——**这是使用者的选择，不是技能的缺陷，但需要在案例里显式说明**。
3. **两份案例合起来才是完整答案。** 产业定位（值不值得研究）+ 估值纪律（价格值不值得买）+ 认知纪律（我会在哪里骗自己）——**第三个维度只有《穷查理宝典》路径会产出，而它恰恰没有出现在姊妹案例里。**

## 6. 可复用要点

### 6.1 使用者视角

1. **想指定书就指定，但要接受它限制了覆盖面。** 要可复现 → 指定；要最大覆盖 → 不指定。
2. **看"未查到"和"证伪条件"两节。** 这两节的可信度高于结论本身。
3. **区分"关于标的的判断"和"关于分析者的判断"。** 芒格式的能力圈结论是后者，不能当看空/看多信号。
4. **注意证据等级标注。** `Explicit` 是书里原话，`Inferred` 是推导，`Composite` 是多来源拼接。
5. **PE 必须带口径。** 本例同一时点三种口径差 2.5 倍。

## 7. 边界（必须写在案例里，否则会被误用）

- 芒格框架**不预测股价**。案例中"不构成错标赔率"不等于"会跌"。
- **能力圈是个人化的约束**，不是对企业的价值判断。芒格本人在同一讲里明确说"这并不意味着你们去做的话是不理智的行为"。
- 该框架**为"避开重大错误"而设计，不为"捕捉高弹性成长"而设计**。用它评价三倍股，结构上必然偏向否定。
- 书中核心案例（可口可乐、喜诗糖果、好市多）都是**消费/品牌/渠道**类生意，护城河机制与制造业代际竞赛不同。**本案例只在"方法论层面"套用，不在"结论层面"套用。**
- 本案例所有数据有明确时点（**行情 2026-09-18 收盘 / 财务 2026-06-30 报告期**），引用时必须带日期。
- 分析过程**未修改知识包内任何文件，未产生任何学习事件数据**。
