# 案例：用 `book-user` 分析一只 A 股个股

> 案例日期：2026-09-20
> 提问原文：`/book-user 分析下A股：中际旭创`
> 配套知识包：`Serenity的瓶颈点投资方法论` + `聪明的投资者`
> 说明：本文是**方法论演示**，所有行情/财务数据均来自公开披露，不构成任何投资建议。

---

## 1. 案例速览

| 项 | 内容 |
|---|---|
| 一句话提问 | `/book-user 分析下A股：中际旭创` |
| 触发技能 | `book-user`（基于已发布知识包回答问题） |
| 自动选书 | 2 本（产业定位 + 估值纪律），**未向用户追问** |
| 外部取数 | 7 次（通达信行情/一致预期/研报评级 + 3 次公开资料检索） |
| 产出 | 1 份完整报告 + 3 张可视化 + 1 段结论回复 |
| 关键结论 | 该标的在书上**不构成瓶颈点**（五因子乘积归零），且**没有安全边际** |

**这个案例真正值得参考的地方不是结论，而是「提问有多短」和「输出有多长、多可核查」之间的落差。**

## 2. 提问方式

### 2.1 原文

```
/book-user 分析下A股：中际旭创
```

一共 18 个字符，包含三件事：

| 成分 | 作用 |
|---|---|
| `/book-user` | 指定用哪个技能——**这是唯一的加载开关**，不能省 |
| `分析` | 意图类型（要判断，不要科普） |
| `A股：中际旭创` | 分析对象 + 市场范围（决定用哪套数据源） |

### 2.2 技能对提问的要求（决定了为什么这样问就够了）

`book-user` 的技能约束里有三条关键设计：

1. **书由 AI 自己选，不由用户选**——「Choose books and chapters yourself; the runtime does not rank or select anything.」
2. **只在一种情况下才允许打断用户**——「Ask the user only when the choice between books would materially change the analysis or when the books conflict.」
3. **不要求用户提供任何背景**——书里已有的框架直接拿来用。

所以提问者**不需要**说「请用五因子框架」「请同时用安全边际」，也不需要指定章节。这些是技能内部的事。

### 2.3 可复用模板

```
/book-user 分析下<市场>：<标的>
```

**变体（按需加一个限定词即可，不要加多）：**

| 场景 | 提问 |
|---|---|
| 指定角度 | `/book-user 用瓶颈点框架看下英伟达` |
| 对比两个标的 | `/book-user 对比宁德时代和比亚迪，用书里的选股标准` |
| 只要估值视角 | `/book-user 从安全边际角度评价贵州茅台当前价格` |
| 验证已有判断 | `/book-user 我判断 XX 是瓶颈点，帮我用五因子反驳一下` |

### 2.4 反面提问（会触发追问或降低质量）

| 反例 | 问题 |
|---|---|
| `/book-user 中际旭创能买吗` | 「能买吗」超出书的能力边界；书回答的是"有没有优势/有没有保护"，不是买卖建议 |
| `/book-user 帮我找一只瓶颈点股票` | `book-user` 是**消费端**技能，不负责选股；这类需求要用书里的规则自己筛 |
| `/book-user 分析下中际旭创，用五因子、安全边际、DCF、技术面` | 一次要太多框架，会同时触发"书冲突"追问 |
| 只写 `/book-user` | 没有分析对象，技能无法起步 |

## 3. 执行轨迹（AI 侧实际做了什么）

提问很短，但执行链有 7 步。使用者了解这个链条，才知道输出为什么可信。

| 步 | 动作 | 要点 |
|---|---|---|
| 1 | 加载技能正文 | `SKILL.md` 规定：从 `booksys books list` 开始，先拿稳定 ID |
| 2 | 列目录 | 得到 2 个已发布知识包及其 `book_id` / `chapter_id` |
| 3 | 读书档案 + 选章 | 共读 2 份 `book.md` + 6 章 `source.md` + 3 章 `concepts.json` + 1 章 `guide.md` |
| 4 | 定框架 | Serenity 管产业定位（Ch1/2/3/4/7/10），Graham 管估值纪律（Ch1/Ch14/Ch20） |
| 5 | 外部取数 | 通达信：行情快照（PE/PB/市值）、90 根日 K、主营构成、研报评级与一致预期 |
| 6 | 事实检索 | 半年报数据、7 月回撤成因、北美云厂商 CapEx 指引 |
| 7 | 分证据等级输出 | 书中材料 / 外部事实 / 推断 三类分开标注，给置信度与证伪条件 |

### 3.1 选书逻辑（为什么是这两本）

| 书 | 承担角色 | 为什么必须 |
|---|---|---|
| `Serenity的瓶颈点投资方法论` | 产业定位 | 该标的正处在书里被明确讨论的光通信/CPO 链上，可直接对照书的七层地图 |
| `聪明的投资者` | 估值纪律 | 产业定位只说"值不值得研究"，不说"价格值不值得买"，需要第二本书补上 |

**两书不冲突，所以技能没有停下来追问。** 如果只有一本覆盖该领域，技能会照常输出；只有当两本给出矛盾结论时才需要用户裁决。

### 3.2 本机调用 `booksys` 的正确姿势（Git Bash）

技能开头写的是 `booksys books list`，但本机该命令**不在 PATH 上**，需要走源码方式：

```bash
export PATH="/c/Windows/System32:/c/Windows:/usr/bin:/bin:$PATH"
cd <book-system 仓库根>
PYTHONPATH=src python -m booksys books list
```

`booksys.bat` 依赖 `cmd`，在 Git Bash 下不可用。

## 4. 结果输出

以下是该次提问的实际输出（正文），未删改。

### 4.0 开场：公开加载了哪些书

| 书 | 承担角色 |
|---|---|
| **Serenity的瓶颈点投资方法论** | 产业定位：它在 AI 光通信链上到底是「瓶颈点」还是「受益者」 |
| **聪明的投资者**（Graham） | 估值纪律：这个价格有没有安全边际 |

### 4.1 结论

**它不是瓶颈点，也不便宜；用这两套方法论在这里都拿不到优势。但这不等于看空。**

**① Serenity 框架：五因子乘积归零。**

- `受限供给 = 0`：书规是「全球玩家三家以上就 pass」。光模块环节至少 8 家（新易盛、天孚、光迅、华工、Coherent、Lumentum、Fabrinet…），而它自己的产能 H1 已到 2215 万只、2029 年目标 9000 万只——**供给恰恰是可扩的**。更能说明问题的是：半年报自己写「光芯片、电芯片、PCB 等物料普遍紧张」——**它是被上游卡的那一方**，真正的卡点在它下面几层（InP 衬底全球仅 2 家、CPO 外置激光源、高纯磷）。
- `低关注度 = 0`：1.09 万亿市值、沪深 300、两融、沪港通，**49 家机构覆盖 2026E**，1800 只基金持仓 12.05%，近 5 个月 11 份研报 100% 买入/增持。书原话：「卖方覆盖数量是反向指标，覆盖越多定价越充分。」
- 剩下三项（确定需求 / 价值捕获 / 催化剂）都满分——所以它是**优秀的「受益者」，不是「瓶颈点」**。

**② Graham 框架：安全边际为负。** 防御型七标准里三条通过（规模、流动比 2.56、利润增长），三条不合格且全在估值上：

| 口径 | 市盈率 | Graham 上限 15× |
|---|---|---|
| 静态（2025 年报） | **101.1×** | 超 6.7 倍 |
| TTM | **53.4×** | 超 3.6 倍 |
| 2026E（49 家） | 31.7× | 超 2.1 倍 |
| 2027E（38 家） | 15.3× | 刚好贴线 |

PB 25.92，**PE×PB = 1383**（Graham 上限 22.5）；股息率 0.23%。Graham 的原话是「安全边际成为了负数」。

### 4.2 一个必须说清的反差

**业绩创纪录，股价从 6 月高点 1416.88 元回撤 34.6%。** 7 月那波 −28.98% 的成因**不是基本面问题**：7/15 中报预告披露收官→资金「利好落地即兑现」集中离场（7/16 主力净流出 35.32 亿居两市第一），叠加美股芯片股抛售与韩股共振；7/30 港股上市当日 −9.15%。**交银国际 8/28 把目标价从 1600 下调到 1488，理由写明「估值中枢调整」，同时把 EPS 预测上调了。** 分歧全在分母上——教科书级的「市场先生」。

### 4.3 关键不确定性（未被抹平）

- 卖方 2026E 净利预测从 4 月到 9 月**被连续上调四次**（272→296→318→345→360 亿）。Graham 要求「估算结果必须偏保守」，持续上调恰恰相反——**一致预期不能当安全边际的分母**。
- **没有逐家核实**「全球几家能做 1.6T 硅光」，用的是公开参与者名单。若实际只有 3 家通过认证，`受限供给` 评分会明显变化。
- **未核实**：2017–2024 逐年是否盈利（Graham 利润稳定性标准）、港股发行对 A 股股东的摊薄比例。
- Serenity 框架的业绩样本诞生于 AI 超级牛市，**本分析同样处在周期里**，无法排除周期滤镜（该书 Ch10 §10.5 自己承认此点）。
- 证伪条件已列 4 条，最值得盯的是：**它的 NPO/XPO/硅光方案是否被写入头部 CSP 的公开 reference design 或标准规范**——若成真，它有机会从「受益者」升级为 Chokepoint。

### 4.4 三张可视化

| 图 | 说明 |
|---|---|
| 五因子乘法判定卡 | 逐因子给通过/归零，末尾直接给出乘积结果 |
| 光通信产业链七层定位图 | 把公司放回 Ch3 的逆向拆解链，直观看出它在第 3 层、真瓶颈在 5–7 层 |
| 市盈率阶梯图 | 5 个口径的 PE 叠上 Graham 15× 红线，一眼看出只有 2027E 贴线 |

**图 3 是整份分析信息密度最高的一张。** 它把「101 倍静态 PE」和「15 倍贴线」放进同一张图，避免了只看一个数字造成的误判。

## 5. 可复用要点

### 5.1 使用者视角

1. **提问越短越好。** 技能内部已经规定了选书逻辑，用户指定框架反而可能触发追问。
2. **不要问「能不能买」。** 书回答的是「有没有优势」和「有没有保护」，这是两个可判断的问题；「能不能买」不是。
3. **重点看「不确定性」和「证伪条件」两节。** 这两节是这套方法最有价值的部分——它主动告诉你它可能错在哪。
4. **注意证据等级标注。** 输出里 `Explicit` 是书里原话，`Inferred` 是推导，`Composite` 是多来源拼接。**不要一律当结论用。**

### 5.2 这套方法真正的用处

它不产出「买/卖」，它产出三样东西：

- **定位**——这个环节在产业链的哪一层，是瓶颈还是受益者；
- **定价充分度**——市场已经知道多少；
- **失效条件**——什么信号出现说明这个判断错了。

第一项决定你要不要继续研究，第二项决定你还有没有超额收益空间，第三项决定你什么时候该撤。

### 5.3 边界（必须写在案例里，否则会被误用）

- 两本书都**没有能力预测股价**。案例中「结论=不构成机会」不等于「会跌」。
- Graham 的 15 倍 PE 上限写于 1972 年的美国市场，**结构性排除掉几乎所有高增长科技企业**。直接套用会得出「永远不能买成长股」，这不是原意。问题始终是「价格有没有给保护」。
- Serenity 的「数全球玩家」规则依赖对产业格局的持续跟踪，**静态快照会过期**。
- 本案例的所有数据有明确时点（行情 2026-09-18 收盘 / 财务 2026-06-30 报告期），**引用时必须带日期**。
