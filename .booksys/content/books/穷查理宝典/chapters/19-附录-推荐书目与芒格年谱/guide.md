# 读前导读（chapter-guide）

> 非剧透：供人类读前/读中阅读，book-coach 可自由读取；**不含章节结论**。
> 读后总结不落库：需要 recap / 概念图谱时，按需从 AI 侧文件现场渲染（AI 侧文件含结论，不得作为读前/读中材料）。

## 本章速览
- **章节**: 19/20 · **所属篇**: 附录（查理·芒格推荐书目与年谱）
- **一句话概括**: 这份资料性附录分为两块——一份芒格亲自推荐、反复提及的书单，以及一份从出生到 2020 年的生平大事记；它不讲授方法，而是呈现「方法从何而来、人生如何铺展」。
- **适合读者**: 想弄清芒格知识底盘由哪些学科构成、又想顺着时间线看清哪些人生节点塑造了他方法论的读者；适合作为全书的「索引」与「背景墙」来读。

## 本章结构
1. 开篇引语：芒格关于「聪明人都每天阅读、自己像长了两条腿的书」的自述
2. 芒格推荐书目（约二十种，横跨科学、进化、心理、历史、商业、传记等）
3. 编辑额外推荐的几本书（三本商业/开拓史相关）
4. 查理·芒格年谱（1924 年出生至 2020 年疫情下的缺席年会）

## 读前问题

- 这份书单里，芒格的阅读明显偏向哪些学科领域？能不能归纳出几条「他怎么读书」的取向？
- 书中很多是传记与自传（卡耐基、洛克菲勒、富兰克林、西蒙……）。传记在他知识结构里扮演什么角色？（推断：是否体现了「读传记数胜过读纯理论」的偏好，可带着此问去印证）
- 年谱里，哪几个节点真正把芒格从「律师」推成了「投资家」？转折点是什么？
- 伯克希尔时期与他的阅读清单之间，能否对应出「读什么、就用在哪」的痕迹？
- 把年谱分阶段看（早年与教育 / 律师与合伙公司 / 伯克希尔合伙 / 慈善与晚年），每个阶段最关键的「转型事件」各是什么？

## 阅读检查点

- [ ] 读到书单时，按学科（科学/进化、心理、历史文明、商业投资、传记自传）给每本书归一次类，看看哪一类最厚。
- [ ] 读到年谱时，停下来用自己的话标出「终止律师生涯（1965）」「任伯克希尔副主席（1978）」等几个断代点，而不是逐条记年份。
- [ ] 看到 2008 年「推荐比亚迪」、2020 年「疫情缺席年会」，联想正文里他关于能力圈与中国机会的论述，建立附录与正文的呼应。

## 作者框架与衔接
**本章采用的方法论**：资料性编排，而非论证性结构。书单以「书名 + 中译出版信息」平列呈现，意不在逐本讲解，而在用「他读什么」反推「他怎么想」；年谱以「年份 + 事件」逐年铺陈，但读者应主动做「分阶段」归纳（早年与教育 → 律师与合伙公司 → 伯克希尔合伙 → 慈善与晚年），而非被动逐条浏览。

**阅读衔接**：本章是全书的入口与背景墙——书单对应前各讲中反复出现的「多元思维模型」「跨学科」「误判心理学」等知识来源；年谱则回应正文中那些案例（喜诗糖果、蓝筹印花、所罗门、比亚迪等）发生的具体时点。建议读完主体章节后再来此处「对号入座」，也适合作为重读时的索引。
