# 第二章：五因子筛选框架——瓶颈点的量化筛选标准

## 2.1 框架总览：五个必要非充分条件

Serenity的瓶颈点投资法并非基于单一指标，而是一个"五因子乘积"的筛选框架。他反复强调：五个因子缺一不可，任一因子归零则整体不构成投资机会。这五个因子是：

**确定需求 × 受限供给 × 低关注度 × 价值捕获 × 催化剂**

这个框架的核心洞察是：仅仅发现一个"重要的"环节是不够的。行业里很多人会说"这个东西也受益于AI"——这在Serenity看来仅仅是受益者思维，不是瓶颈点思维。瓶颈点需要满足一个乘积关系：需求必须足够确定（不能只是宏观叙事），供给必须足够窄（不能有太多玩家），市场认知必须滞后（不能已被充分定价），公司必须能从中捕获价值（不能有位置没利润），而且还需要有催化剂来触发价格发现。

## 2.2 第一因子：确定需求（Deterministic Demand）

需求端必须足够确定。这不仅仅是"AI是个大趋势"这种模糊叙事。Serenity对需求端的验证锚定在巨头的实际资本开支上——微软、Meta、谷歌、亚马逊、甲骨文、xAI，这六家超大规模厂商在2025年的合计资本开支已经突破5200亿美元，2026年市场一致预期达到6300亿至6800亿美元区间。

他的逻辑是：钱流到哪，订单就到哪。追踪CapEx而非收入，是验证需求确定性的核心方法。收入可以被会计手段修饰，但数千亿美元的硬件采购承诺是物理事实。

此外，他还关注架构迁移带来的需求增量。例如AI数据中心从电连接向光连接迁移时，数据带宽需求的指数级增长——单机柜功率从10kW飙到100kW甚至200kW——风冷已经物理上无法解决问题，液冷从"选项"变成了"必须"。这种由物理极限驱动的需求，确定性远超由商业模式驱动的需求。

Serenity在推文中反复提及AMZN Trainium、MSFT Maia、Google TPU和NVDA推动800V DC，表明他并非孤立地审视某家小公司，而是将其置于巨头资本开支和架构迁移的大背景中评估需求。

## 2.3 第二因子：受限供给（Constrained Supply）

所谓瓶颈点，不是轻飘飘的"这个东西也受益"，而是"没它不行"且"短期不好复制"。供给约束的来源包括：

**产能壁垒**：建一条InP衬底产线需要数年时间、数亿美元投入和极端复杂的工艺know-how。这不是市场需求来了就能快速扩产的。

**认证周期**：光通信产业链的客户认证周期通常在18-36个月。即使竞争对手有钱建产线，客户认证这道关卡也意味着短期内供给无法增加。

**良率门槛**：化合物半导体材料的良率提升是一个极其缓慢的过程。良率从60%提到80%可能需要两年，投入成本呈指数级上升。

**原料约束**：高纯度磷原料（6N以上）的全球供应商极少，这是InP衬底上游的又一个瓶颈。层层穿透下去，每一层都有自己的供给约束。

Serenity的供给分析有一个核心动作：数全球玩家。这是他最著名的操作规则——"数一数这家公司所在的环节，全球有几个玩家。三家以上，pass！因为竞争充分，没有定价权。"这个规则看似粗暴，背后是一个深刻的产业洞察：只有当供给端形成自然垄断或双寡头结构时，瓶颈点才能在需求爆发时获得不对称的定价权。

他还严格区分了Bottleneck和Chokepoint：

- Bottleneck是产能或输出控制——某个材料、工艺、fab allocation让整个链条放量受限。
- Chokepoint是架构依赖——即使别人也能生产类似东西，但系统、reference design、qualification cycle、客户路线已经围绕某个方案展开，短期不能热插拔替换。

他反复强调的真正机会，恰恰是Chokepoint而不是普通的Bottleneck。

## 2.4 第三因子：低关注度（Low Market Attention）

低关注度 = 真正的价格洼地。在这个因子上，Serenity的投资哲学与机构研究者形成了鲜明对比：

卖方分析师覆盖数量是一个反向指标——覆盖越多，定价越充分。AXTI在Serenity开始研究时，几乎没有卖方覆盖，市值仅十几亿美元。等到行业共识形成、分析师开始覆盖时，超额收益的主体部分已经实现。

机构持仓比例也是一个重要的低关注度指标。SIVE、NBIS、RKLB等标的在Serenity最初公开推荐时，机构持股比例极低；后来当机构持续加仓后，股价创出历史新高。他的观点是：对这些被忽略的瓶颈标的来说，零售投资者往往先于机构完成早期定位，机构随后的加仓才推动主升浪。

低关注度还有一个维度：地域偏见。SIVE是一家瑞典公司，RPI是英国公司——这些非美国本土的小市值公司天然处于分析师的盲区。欧洲小盘股的分析覆盖密度远低于美股，意味着更多的定价错误。

## 2.5 第四因子：价值捕获（Value Capture）

真瓶颈转化为超额收益，中间隔着几个条件。Serenity对此非常清醒：位置关键不等于股票会涨。价值捕获因子检查以下条件：

**定价权**：公司在客户面前有没有议价能力？如果它是全球仅有的两家供应商之一，而客户的AI数据中心扩张离不开它的产品——那它就是定价方。

**毛利空间**：高毛利是真垄断的外部信号。如果一家公司在产业链中占据不可替代的位置但毛利率只有20%，那说明要么它没有定价权，要么成本结构有问题。

**客户锁定**：客户的切换成本有多高？一旦产品通过认证并嵌入客户的reference design，客户要更换供应商的代价是巨大的——需要重新走18-36个月的认证流程。这就是客户锁定的来源。

**供应份额**：公司在全球供给中占多大比例？AXTI的25-33%是一个关键数字——足够大以至于如果它停产，整个光子学建设进度将受到严重影响，但又不是100%，避免了单点故障后的反垄断风险。

**不被稀释**：小市值公司增长通常需要融资，但频繁的股票增发会稀释现有股东的权益。Serenity会评估公司的现金流能否支持产能扩张，以及是否需要大规模稀释性融资。

他曾明确指出：很多所谓的"瓶颈股"其实只是beneficiary——需求来了它会受益，但客户可以绕开它，竞争对手可以扩产，价格可能被压回去。真正的瓶颈点必须同时满足位置关键+客户锁死+定价权+有限竞争这四个条件。

## 2.6 第五因子：催化剂（Catalyst）

长期空间固然重要，但短期催化剂是价格引擎。即使是最正确的non-consensus判断，如果没有催化剂来触发价格重估，也可能长期"对但赚不到钱"。Serenity关注的催化剂类型包括：

**财报验证**：当公司财报中的收入/毛利/backlog数据验证了瓶颈逻辑，市场开始重新定价。RPI的58%营收增长就是最经典的财报催化剂案例。

**客户量产**：当云厂商的ASIC芯片进入量产阶段，对光模块/衬底/激光器的需求从"预期"变成"订单"。

**产业事件**：Jabil fireside chat、OFC光通信大会等行业活动的信息披露。

**政策驱动**：CHIPS Act拨款、出口管制清单更新——这些政策事件可以瞬间改变供给格局。例如出口管制限制了某国供应商，全球需求被迫转向仅存的一两家供应商。

**指数纳入**：当冷门小盘股被纳入罗素2000或相关行业指数，被动基金必须买入。

**Nasdaq双重上市**：非美国公司在美国二次上市，打开了美国投资者的入场通道（RPI就是通过此路径触发了流动性溢价）。

**M&A**：巨头意识到供应链瓶颈后开始的垂直整合收购潮——Serenity预判COHR等公司将启动"垂直整合购买潮或产能锁定潮"。

**空头拥挤**：当一只被忽视的股票同时有大量的空头头寸，任何正面催化剂都可能触发轧空。

他特别强调：催化剂不应该是"我猜它会涨"的模糊预期，而必须是具体可验证的事件。每一个仓位在建立时，应该有一个明确的催化剂清单和时间窗口。

## 2.7 因子的乘积关系与致命缺陷原则

Serenity的五因子框架隐含一个重要的数学结构——乘积关系，而非加法关系。任何一个因子为零，整体机会归零：

- 确定需求 = 0 → 这是纯投机，没有锚
- 受限供给 = 0 → 这是受益者，不是瓶颈点
- 低关注度 = 0 → 超额收益已被定价完毕
- 价值捕获 = 0 → 好公司不等于好股票
- 催化剂 = 0 → 正确但可能长期不兑现

这一乘积关系对应了他在实践中反复体现的"致命缺陷短路径"原则：不必在每个因子上追求完美，但如果某一因子明显不满足，就直接排除该标的。例如某公司在产业链中位置很重要，但全球有5家竞争对手——供给端不满足，直接pass。

这种乘积思维也解释了为什么Serenity的公开持仓数量极少（通常集中在少数几个高确信度标的）——五因子同时满足的公司凤毛麟角。

## 2.8 框架的跨资产适用性

最值得注意的是，Serenity的方法论并非局限于半导体硬件。同样的五因子框架被他无缝延伸到了加密资产领域：

在加密语境下，确定需求对应链上真实用户增长和协议收入，受限供给对应共识机制中的质押锁定或代币燃烧机制，低关注度对应CEX/DEX的用户渗透率差距，价值捕获对应代币经济学中的费用分配机制，催化剂对应协议升级、ETF审批或监管政策变化。

2026年他在BTC $62,000和ETH $1,750买入IBIT和ETHA的波段操作，就是基于ETH/BTC汇率比压缩至多年低点的统计套利逻辑——这本质上也是"低关注度+催化剂"因子的加密版本。
